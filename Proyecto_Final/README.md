# Proyecto Final

## Descripción
Proyecto final para RTOS.

## Estructura del Proyecto

```
Proyecto_Final/
├── server/
│   ├── app.py
│   ├── requirements.txt
│   ├── static/
│   │   ├── css/
│   │   ├── js/
│   │   └── img/
│   └── templates/
└── README.md
```

## Instalación

1. Instalar dependencias:
```bash
pip install -r server/requirements.txt
```

## Uso

Ejecutar el servidor:
```bash
cd server
python app.py
```
