Inicializa el controlador PWM para el LED RGB verde. 

Configura el timer LEDC y el canal PWM para controlar el LED verde. Esta función debe llamarse una vez durante la inicialización del sistema antes de usar cualquier otra función de este módulo.

Proceso de inicialización\+:
\begin{DoxyEnumerate}
\item Configura el timer LEDC con resolución de 8 bits y frecuencia de 5k\+Hz
\item Configura el canal LEDC para el GPIO del LED verde
\item Inicia el LED con brillo 0\% (apagado)
\end{DoxyEnumerate}

\begin{DoxyReturn}{Devuelve}
true si la inicialización fue exitosa, false en caso contrario 
\end{DoxyReturn}

Establece el brillo del LED verde como porcentaje. 

Convierte el porcentaje (0-\/100) a valor PWM (0-\/255) y actualiza el LED. Valores fuera de rango se limitan automáticamente a 0-\/100.

Nota\+: Esta función requiere que \doxylink{rgb__led_8c_a3998750ac5327295428745cd6b755701}{rgb\+\_\+led\+\_\+init()} haya sido llamada previamente. Si no está inicializado, la función no realizará ninguna acción.
