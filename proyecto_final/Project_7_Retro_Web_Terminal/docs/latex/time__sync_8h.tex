RESUMEN\+: Header file para la sincronización de tiempo usando SNTP (Simple Network Time Protocol). Este módulo permite obtener la hora y fecha actual del sistema, necesaria para el sistema de horarios del ventilador.

Funcionalidades\+:
\begin{DoxyItemize}
\item Sincronización automática con servidores NTP
\item Configuración de zona horaria para Colombia (UTC-\/5)
\item Persistencia de hora en NVS para restaurar después de reinicio
\item Establecimiento manual de hora cuando SNTP no está disponible
\item Obtención de día de la semana y hora actual en formato español
\end{DoxyItemize}
