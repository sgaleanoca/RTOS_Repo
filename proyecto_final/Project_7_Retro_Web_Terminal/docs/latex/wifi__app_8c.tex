Implementación del módulo de Wi\+Fi en modo AP+\+STA (Access Point + Station). Este módulo configura el ESP32 para funcionar simultáneamente como\+:
\begin{DoxyItemize}
\item Access Point (Soft\+AP)\+: Crea su propia red Wi\+Fi para acceso local
\item Station (STA)\+: Se conecta a una red Wi\+Fi externa para tener Internet
\end{DoxyItemize}\hypertarget{wifi__app_8c_functionality}{}\doxysubsection{\texorpdfstring{Funcionalidades}{Funcionalidades}}\label{wifi__app_8c_functionality}

\begin{DoxyItemize}
\item Inicializa la pila de red TCP/\+IP
\item Configura el ESP32 como punto de acceso Wi\+Fi (red local)
\item Se conecta a una red Wi\+Fi externa para tener Internet (SNTP, etc.)
\item Maneja eventos de conexión/desconexión de clientes y estaciones
\item Reintentos automáticos de conexión a la red externa
\end{DoxyItemize}\hypertarget{wifi__app_8c_usage}{}\doxysubsection{\texorpdfstring{Uso en el sistema}{Uso en el sistema}}\label{wifi__app_8c_usage}
Los usuarios pueden conectarse a la red "{}\+ESP32\+\_\+\+Server"{} y acceder al servidor web para controlar el sistema. El ESP32 también se conecta a la red "{}\+Mondongo"{} para tener acceso a Internet (SNTP, etc.).
