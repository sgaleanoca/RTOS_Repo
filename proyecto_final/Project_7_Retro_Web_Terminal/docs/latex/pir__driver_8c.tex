Inicializa el driver del sensor PIR. 

Configura el pin GPIO como entrada con interrupciones en ambos flancos (subida y bajada) para detectar cambios en el estado del sensor.

Si se proporciona una cola de eventos, los eventos de movimiento se enviarán automáticamente a través de la cola cuando se detecten cambios. Esto permite procesamiento asíncrono de eventos de movimiento en una tarea separada.

Proceso de inicialización\+:
\begin{DoxyEnumerate}
\item Valida que el pin GPIO sea válido
\item Configura el pin GPIO como entrada sin pull-\/up/pull-\/down
\item Configura interrupciones en ambos flancos (GPIO\+\_\+\+INTR\+\_\+\+ANYEDGE)
\item Instala el servicio de ISR de GPIO (si no está instalado)
\item Registra el handler de interrupción para el pin
\end{DoxyEnumerate}


\begin{DoxyParams}{Parámetros}
{\em pir\+\_\+gpio} & Número del pin GPIO donde está conectado el sensor PIR \\
\hline
{\em pir\+\_\+queue} & Cola de eventos donde se enviarán las notificaciones de movimiento. Puede ser NULL si no se necesita notificación asíncrona. La cola debe ser creada previamente con x\+Queue\+Create().\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Devuelve}
true si la inicialización fue exitosa, false en caso contrario
\end{DoxyReturn}
\begin{DoxyNote}{Nota}
La cola de eventos debe ser creada antes de llamar a esta función. Ejemplo\+: Queue\+Handle\+\_\+t pir\+\_\+queue = x\+Queue\+Create(10, sizeof(pir\+\_\+event\+\_\+t));

Muchos módulos PIR ya incluyen electrónica interna (pull-\/up, filtrado), por lo que no se configuran pull-\/up/pull-\/down en el GPIO. 
\end{DoxyNote}

Lee el estado actual del sensor PIR. 

Lee directamente el nivel del pin GPIO para determinar si hay movimiento detectado. Esta función es síncrona y puede ser llamada desde cualquier tarea.

\begin{DoxyReturn}{Devuelve}
true si hay movimiento detectado (GPIO en nivel alto), false si no hay movimiento (GPIO en nivel bajo) o si el driver no está inicializado
\end{DoxyReturn}
\begin{DoxyNote}{Nota}
Esta función lee el estado actual del GPIO, no el último evento. Para recibir notificaciones de cambios, usar la cola de eventos en \doxylink{pir__driver_8c_a0eeed3cd7f30d6213009385f03ad018a}{pir\+\_\+init()}.

Esta función es thread-\/safe porque gpio\+\_\+get\+\_\+level() es thread-\/safe. 
\end{DoxyNote}

ISR (Interrupt Service Routine) del sensor PIR. 

Esta función se ejecuta cuando se detecta un cambio en el pin GPIO del sensor PIR (flanco de subida o bajada). Lee el nivel actual del GPIO y envía un evento a la cola de Free\+RTOS si está configurada.

Características importantes\+:
\begin{DoxyItemize}
\item Debe estar marcada con IRAM\+\_\+\+ATTR para ejecutarse desde IRAM (memoria rápida)
\item Usa x\+Queue\+Send\+From\+ISR() para enviar eventos de forma thread-\/safe desde ISR
\item Hace yield si una tarea de mayor prioridad fue despertada
\end{DoxyItemize}
