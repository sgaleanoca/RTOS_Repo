===== ARQUITECTURA DE TAREAS Y COLAS ===== Esta función implementa una tarea de Free\+RTOS que procesa comandos de forma asíncrona.

Flujo de comunicación mediante colas\+:
\begin{DoxyEnumerate}
\item Handler HTTP recibe comando del cliente web
\item Handler envía comando a gpio\+\_\+command\+\_\+queue (x\+Queue\+Send)
\item Esta tarea recibe comando de gpio\+\_\+command\+\_\+queue (x\+Queue\+Receive, bloqueante)
\item Procesa comando con \doxylink{terminal__commands_8c_a6c2c567b2888c28a52c142cd226fa8b9}{process\+\_\+terminal\+\_\+command()}
\item Envía respuesta a gpio\+\_\+response\+\_\+queue (x\+Queue\+Send)
\item Handler HTTP recibe respuesta de gpio\+\_\+response\+\_\+queue (x\+Queue\+Receive)
\item Handler envía respuesta al cliente web
\end{DoxyEnumerate}

Ventajas\+:
\begin{DoxyItemize}
\item El servidor HTTP no se bloquea esperando procesamiento
\item Múltiples comandos pueden estar en cola simultáneamente
\item Thread-\/safe gracias a las colas de Free\+RTOS
\item Permite manejar picos de tráfico sin perder comandos

===== EXPLICACIÓN DE LA TAREA ===== Esta es una tarea de Free\+RTOS que se ejecuta de forma independiente para procesar comandos de la terminal web de manera asíncrona.

Arquitectura\+:
\begin{DoxyEnumerate}
\item El handler HTTP (/cmd) recibe un comando del cliente web
\item El handler envía el comando a gpio\+\_\+command\+\_\+queue (no bloquea)
\item Esta tarea recibe el comando de la cola (bloqueante)
\item Procesa el comando usando \doxylink{terminal__commands_8c_a6c2c567b2888c28a52c142cd226fa8b9}{process\+\_\+terminal\+\_\+command()}
\item Envía la respuesta a gpio\+\_\+response\+\_\+queue
\item El handler HTTP recibe la respuesta y la envía al cliente
\end{DoxyEnumerate}

Ventajas de esta arquitectura\+:
\begin{DoxyItemize}
\item El servidor HTTP no se bloquea esperando procesamiento
\item Múltiples comandos pueden estar en cola simultáneamente
\item El procesamiento es thread-\/safe gracias a las colas
\item Permite manejar picos de tráfico sin perder comandos
\end{DoxyItemize}

===== USO DE COLAS ===== gpio\+\_\+command\+\_\+queue (entrada)\+:
\begin{DoxyItemize}
\item x\+Queue\+Receive() espera indefinidamente (port\+MAX\+\_\+\+DELAY) hasta recibir un comando
\item Cuando recibe un comando, lo copia a la variable local \textquotesingle{}cmd\textquotesingle{}
\item La cola es thread-\/safe\+: múltiples handlers HTTP pueden enviar simultáneamente
\end{DoxyItemize}

gpio\+\_\+response\+\_\+queue (salida)\+:
\begin{DoxyItemize}
\item x\+Queue\+Send() envía la respuesta con el mismo command\+\_\+id
\item Timeout de 100ms\+: si la cola está llena, espera máximo 100ms
\item Si falla, registra un warning pero continúa (el handler HTTP manejará el timeout)
\end{DoxyItemize}
