 \doxysubsection*{ARCHIVO\+: \doxylink{registros_8c}{registros.\+c} }

RESUMEN\+: Implementación de la gestión de registros de horarios del ventilador. Este módulo proporciona funciones para almacenar y leer registros de forma persistente en la partición SPIFFS del ESP32.

Funcionalidades\+:
\begin{DoxyItemize}
\item Creación automática del archivo registros.\+json si no existe
\item Guardado de registros en formato JSON en /spiffs/registros.json
\item Lectura de todos los registros almacenados
\item Verificación de registros activos para el día y hora actual
\item Persistencia de datos tras reinicio del ESP32
\end{DoxyItemize}

Los registros se utilizan desde el módulo \doxylink{web__server_8c}{web\+\_\+server.\+c} a través de los endpoints HTTP GET /registros y POST /registros, y desde \doxylink{fan__control_8c}{fan\+\_\+control.\+c} para el modo SCHEDULE del ventilador.

Formato de registro\+: \{ "{}dia"{}\+: "{}lunes"{}, "{}hora"{}\+: "{}14\+:30"{}, "{}velocidad"{}\+: 50, "{}id"{}\+: "{}1234567890"{} \}
