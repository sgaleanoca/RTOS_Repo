RESUMEN\+: Implementación de la sincronización de tiempo usando SNTP (Simple Network Time Protocol). Este módulo permite obtener la hora y fecha actual del sistema, necesaria para el sistema de horarios del ventilador.

Funcionalidades\+:
\begin{DoxyItemize}
\item Sincronización automática con servidores NTP (co.\+pool.\+ntp.\+org)
\item Configuración de zona horaria para Colombia (UTC-\/5)
\item Persistencia de hora en NVS para restaurar después de reinicio
\item Establecimiento manual de hora cuando SNTP no está disponible
\item Obtención de día de la semana y hora actual en formato español
\end{DoxyItemize}

Características\+:
\begin{DoxyItemize}
\item Restauración automática de hora desde NVS al reiniciar
\item Fallback a hora manual si SNTP no puede sincronizar
\item Soporte para zona horaria de Colombia (COT5)
\item Validación de sincronización antes de usar funciones de tiempo
\end{DoxyItemize}
